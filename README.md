## PROJECT - 1 : Best Places Webpage (HTML)

## Algorithm

1. **Start** by creating an HTML document.
2. **Define** a `<h1>` header with the title "The Best Places According to Tapaswi".
3. **Add** a `<h2>` subheader with the text "The Best 2 Places of All-Time." to introduce the list.
4. **Insert** a `<hr />` tag to create a horizontal line separator between the title and the place entries.
5. **For each** place in the list of 2 favorite places:
   1. **Create** a `<h3>` header with the name of the place.
   2. **Add** a `<p>` paragraph with a short description of the place.
6. **End** the document.

## PROJECT - 2 : Birthday Invitation Webpage (HTML)

## Algorithm

1. **Start** by creating an HTML document.
2. **Define** a `<h1>` header with the title "Welcome to Tapaswi's Birthday!".
3. **Add** a `<h2>` subheader with the birthday date.
4. **Insert** an `<img>` tag to display a birthday image.
5. **Create** a `<h3>` header for the things to bring.
6. **Add** an unordered list `<ul>` containing the items to bring.
7. **Create** another `<h3>` header for the party location.
8. **Add** a `<p>` paragraph describing the party location.
9. **Insert** an `<a>` tag to provide a link to the party location on Google Maps.
10. **End** the document.
